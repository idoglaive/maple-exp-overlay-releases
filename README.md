# Maple EXP Overlay

A small panel for **MapleStory Classic World** that shows your EXP/hr, time to the next level,
kills per minute, mesos and loot, your best EXP/hr per map with a shared leaderboard, and
celebrates rare drops with your friends. It only reads what's on your screen: it never touches the
game's memory or files and never presses keys for you.

## Download

**[Download MapleExpOverlay.zip (latest)](https://github.com/idoglaive/maple-exp-overlay-releases/releases/latest/download/MapleExpOverlay.zip)**

1. Unzip it anywhere (e.g. your Documents folder).
2. Open the `MapleExpOverlayuntime` folder and double-click **`pythonw.exe`**. That's Python
   itself, signed by the Python Software Foundation, so Windows Smart App Control lets it run.
   (Shortcuts and .cmd launchers to it get blocked by Smart App Control, so start it this way.)
3. Run the game windowed or borderless, press **Ctrl+Alt+S** and drag a box around the
   `HP[…] MP[…] EXP …[…%]` row at the bottom. "How to use.txt" explains everything else.

It updates itself: when a new version is out, a green **UPDATE** badge appears in the panel's
title bar. Click it to restart into the new version.
