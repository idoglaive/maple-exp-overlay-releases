# Maple EXP Overlay

A small panel for **MapleStory Classic World** that shows your EXP/hr, time to the next level,
kills per minute, mesos and loot per hour, and celebrates rare drops with your friends.
It only reads what's on your screen: it never touches the game's memory or files and never
presses keys for you.

## Download

**[Download MapleExpOverlay.zip (latest)](https://github.com/idoglaive/maple-exp-overlay-releases/releases/latest/download/MapleExpOverlay.zip)**

1. Unzip it anywhere and run `MapleExpOverlay.exe`. If Windows says "Windows protected your PC",
   click **More info** → **Run anyway** (the exe isn't code-signed).
2. Run the game windowed or borderless, press **Ctrl+Alt+S** and drag a box around the
   `HP[…] MP[…] EXP …[…%]` row at the bottom.
3. That's it. "How to use.txt" in the zip explains every number and hotkey.

It updates itself: when a new version is out, a green **UPDATE** badge appears in the panel's
title bar. Click it to restart into the new version.
